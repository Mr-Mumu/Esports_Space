# 电竞空间（Esports Space）— 产品设计文档

> **版本**：v1.1  
> **日期**：2026-03-26  
> **状态**：已评审  
> **最低 SDK**：API 26 (Android 8.0)，推荐 API 28+  
> **目标设备**：10-12.9 英寸 Android 平板，横屏锁定

---

## 1. 产品概述

### 1.1 定位

Android 平板上的 **电竞沉浸式 Launcher 桌面**。用户进入后，整个屏幕被电竞氛围包裹，只展示游戏和电竞相关内容，打造沉浸式游戏体验平台。

### 1.2 目标用户

个人消费者（家用 / 宿舍场景），追求沉浸游戏体验的玩家。

### 1.3 产品形态

Android Launcher App（可设为默认桌面），原生 Kotlin/Java 开发。

### 1.4 核心差异点

**智能电竞 Agent**（桌面精灵）— 具备 7 维感知能力，根据用户实时上下文主动推荐游戏、直播、休息等。

### 2.2 四层架构说明

1. **展示层（Launcher UI）**：6 大功能模块的界面，横屏平板优化布局
2. **智能引擎层（Agent Core）**：本地感知采集 → 推荐决策（本地规则 + 云端模型协同）→ 生成主动推荐卡片
3. **基础设施层**：Room 本地数据库、性能采集、网络通信、Launcher 系统集成
4. **云服务层（远端）**：内容聚合（资讯/直播/新游戏）、推荐增强、可选的用户画像同步

### 2.3 设计原则

- **离线可用**：本地感知 + 本地规则引擎保证断网时 Agent 仍能工作
- **云端增强**：联网时获取外部内容 + 更精准推荐
- **隐私优先**：敏感数据（健康、日历等）仅在本地处理，云端只接收脱敏行为摘要

## 3. 主界面设计

### 3.1 三套预设主题

| 主题 | 风格 | 布局 |
|------|------|------|
| **霓虹科技** | 暗黑底 + 青紫霓虹光效 | 三列并排 + 性能图表面板 |
| **奢华精密** | 深炭黑 + 琥珀金 + 毛玻璃 | 错落卡片 + 心电图背景 + 右侧面板 |
| **星系辐射** | 游戏蒙版底图 + 心电图 + 琥珀金 | 中心向外辐射星系布局 |

### 3.2 主界面布局（以"星系辐射"主题为例）

**背景层**：
- 底图：用户最近常玩游戏的模糊暗化蒙版图（~78% 不透明度暗色遮罩）
- 心电图：CPU 频率（琥珀金线）和 GPU 频率（青色线）两条实时波形在同一坐标系，贯穿全屏背景，半透明处理

**游戏区域（~70% 屏幕宽度）— 中心辐射布局**：
- **中心（猜你想玩）**：2-3 张大尺寸游戏海报，占据视觉焦点
- **第二环（最近常玩）**：4-5 个中等 Logo 图标，围绕中心轨道分布
- **外环（不常玩）**：6-7 个小 Logo 图标，散落边缘，低透明度
- **新游推荐**：散布在二三环间，带 NEW 标识和金色呼吸脉冲光晕
- 无边框、无网格，有机的星系分布

**右侧信息面板（~30% 宽度）**：
- 性能数值（CPU/GPU温度、RAM、延迟、FPS）+ "性能调节 →" 跳转按钮
- 资讯列表（3 条，LIVE 红点标识）
- 个人数据摘要（今日游戏时长 / 本周游戏天数）— MVP 阶段仅展示时长类数据，胜率等战绩数据留到二期对接游戏 API 后开放

**桌面精灵**：AI Agent 浮动角色，底部区域悬浮

**底部导航**：极简毛玻璃胶囊条（数据中心、设置、搜索）

**顶部状态栏**：仅时间 + Wi-Fi / 电量，极简

### 3.3 交互设计

- 游戏海报/图标：单击启动，长按弹出菜单（查看数据/移除/锁定位置）
- 性能指标：点击展开详细面板 + 跳转性能调节 App
- Agent 精灵：点击展开推荐列表 / 拖拽移动 / 长按进入设置 / 双击执行最新推荐
- 底部导航：点击进入对应全屏面板

## 4. 智能电竞 Agent 设计

### 4.1 形态

半透明几何多面体光粒子生物（默认），悬浮在桌面上。平时安静"漂浮呼吸"，有推荐时弹出毛玻璃气泡对话。

### 4.2 感知引擎（7 维度）

| 维度 | 数据来源 | 本地/云端 | 示例推荐 |
|------|---------|----------|---------|
| 时间感知 | 系统时钟 | 本地 | "深夜了，来一局安静的单机放松？" |
| 使用习惯 | 本地 Room DB 记录 | 本地 | "你已办公3小时，来局轻松游戏" |
| 设备状态 | 系统 API（电量/温度/存储） | 本地 | "电量仅20%，建议先充电再开大型游戏" |
| 日历日程 | CalendarProvider（需授权） | 本地 | "30分钟后有会议，推荐一局快节奏的" |
| 健康数据 | Health Connect API / 手环 SDK | 本地 | "心率偏高，建议玩休闲类游戏" |
| 社交状态 | 好友在线状态（预留，二期） | 云端 | "你的好友XX正在玩原神，要组队吗？" |
| 外部内容 | 云端内容聚合 API | 云端 | "LPL决赛正在直播！" / "新游上线了" |

### 4.3 推荐决策流程

```
感知数据采集（定时 + 事件触发）
        │
        ▼
┌─────────────────┐
│ 本地规则引擎     │ ← 基础规则（时间段推荐、疲劳提醒、电量预警等）
│ (离线可用)       │
└────────┬────────┘
         │ 联网时
         ▼
┌─────────────────┐
│ 云端推荐增强     │ ← 个性化模型 + 外部内容（赛事/新游/资讯）
│ (可选增强)       │
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│ 推荐卡片生成     │ → 气泡对话 / 通知 / 桌面卡片
│ + 优先级排序     │
└─────────────────┘
```

### 4.4 推荐触发策略

- **被动触发**：用户点击精灵时展示当前推荐列表
- **主动触发**（有节制）：
  - 最多每 30 分钟主动弹出一次
  - 用户忽略 2 次后该类推荐当天不再弹出
  - 游戏中绝对不打扰（检测前台应用）
  - 用户可在设置中调整推荐频率或关闭

### 4.5 精灵交互

| 操作 | 响应 |
|------|------|
| 点击 | 展开推荐列表面板（最近 3-5 条推荐） |
| 拖拽 | 移动精灵位置 |
| 长按 | 进入 Agent 设置 |
| 双击 | 快速执行最新推荐 |
| 闲置 | 浮动 / 旋转微动画，偶尔变换形态 |

### 4.6 Agent 设置

| 设置项 | 说明 |
|--------|------|
| 外观形象 | 预设形象库（5-8 款）+ 自定义导入（静态图/GIF/Lottie 动画），形象与动效分层 |
| 推荐频率 | 高 / 中 / 低 / 仅手动 |
| 感知权限 | 逐项开关（日历、健康数据等） |
| 推荐偏好 | 偏爱的游戏类型、是否推荐新游、是否推荐直播 |
| 免打扰时段 | 自定义不主动弹出的时间段 |
| 开关 | 一键关闭 / 开启 Agent |

### 5.2 电竞资讯 / 赛事

| 要素 | 设计 |
|------|------|
| 数据来源 | 云端内容聚合 API |
| 内容类型 | 赛事直播预告（含倒计时）、赛果战报、转会新闻、版本更新 |
| 展示 | 主界面右侧紧凑列表（3条），LIVE 红点标识 |
| 详情 | 点击进入资讯详情（WebView），或跳转直播 |
| 个性化 | 根据常玩游戏自动筛选相关赛事 |
| 离线 | 缓存最近 20 条资讯 |

### 5.3 个人数据中心

| 要素 | 设计 |
|------|------|
| 入口 | 底部导航"数据中心"，进入全屏面板 |
| 核心数据 | 今日/本周/本月游戏时长、各游戏占比饼图、每日时段热力图 |
| 战绩 | 预留接口，后续对接游戏 API（MVP 先展示时长类数据） |
| 趋势 | 7天 / 30天游戏时长折线图 |
| 健康提示 | 日均游戏超阈值时温和提醒 |
| 存储 | 全部本地 Room DB |
| 主界面摘要 | 右侧"今日 Xh / 本周X天"快速预览（MVP 仅时长数据，胜率留到二期） |

### 5.4 直播 / 视频推荐

| 要素 | 设计 |
|------|------|
| 数据来源 | 云端 API 聚合主流平台（斗鱼/虎牙/B站） |
| 主界面 | 资讯区域 LIVE 标识入口 |
| 播放 | Deep Link 跳转后由目标 App 自行决定是否 PiP；WebView 备用方案下支持应用内 PiP 浮窗播放 |
| 个性化 | 根据常玩游戏推荐相关主播/赛事 |
| 集锦 | 精彩操作/赛事回放短视频，详情页竖向信息流 |

### 5.5 设备性能监控

| 要素 | 设计 |
|------|------|
| 主界面 | 右侧紧凑数值（CPU温度、RAM、延迟、电量）+ 可选指标（GPU温度/频率，依设备能力） |
| 背景心电图 | CPU + GPU 频率双线同一坐标系，融入桌面背景 |
| 数据采集 | 前台 `Service` + `CoroutineScope` 定时协程（5秒间隔），非 `WorkManager` |
| 指标可用性 | CPU温度通过 `HardwarePropertiesManager`（需 `DEVICE_POWER` 权限）或 `/sys/class/thermal/`；GPU温度/频率在非Root设备上可能不可用，采用降级策略：不可读时隐藏该指标并显示"—"；FPS 仅能监测 Launcher 自身帧率，无法监测第三方游戏帧率，面板中标注为"桌面帧率" |
| 性能调节 | "性能调节 →" 按钮，Intent 跳转外部性能调节 App |
| Agent 联动 | 温度过高/电量低/网络差时，精灵主动弹出建议 |
| 详情面板 | 点击展开完整性能面板：历史趋势、各项详情、存储分析 |
| 降级方案 | 对于无法获取的指标，UI 隐藏对应区域或显示"不支持"，不影响其他功能正常运行 |

## 6. 数据模型

### 6.1 本地数据（Room DB）

**GameRecord** — 游戏记录
- `packageName: String` (PK)
- `displayName: String`
- `iconUri: String`
- `posterUri: String?`
- `category: Enum(PREDICTED, FREQUENT, INFREQUENT, NEW)`
- `totalPlayTime: Long` (毫秒)
- `lastPlayedAt: Long` (时间戳)
- `launchCount: Int`
- `pinned: Boolean`

**PlaySession** — 游戏会话
- `id: Long` (PK, auto)
- `packageName: String` (FK → GameRecord)
- `startTime: Long`
- `endTime: Long`
- `durationMs: Long`

**DeviceSnapshot** — 设备快照
- `id: Long` (PK, auto)
- `timestamp: Long`
- `cpuTemp: Float?`
- `gpuTemp: Float?` （非 Root 设备可能不可用）
- `cpuFreqMhz: Int?`
- `gpuFreqMhz: Int?` （非 Root 设备可能不可用）
- `ramUsagePercent: Float`
- `networkLatencyMs: Int`
- `batteryPercent: Int`

**AgentEvent** — Agent 事件
- `id: Long` (PK, auto)
- `timestamp: Long`
- `eventType: Enum(RECOMMENDATION, REMINDER, ALERT)`
- `triggerSource: String`
- `content: String`
- `userAction: Enum(ACCEPTED, DISMISSED, IGNORED)?`

**UserPreference** — 用户偏好
- `key: String` (PK)
- `value: String`
- `updatedAt: Long`

## 7. 技术要点

| 领域 | 方案 |
|------|------|
| Launcher 实现 | 自定义 `LauncherActivity`，声明 `CATEGORY_HOME` intent-filter，处理 HOME 键 `onNewIntent`，不支持系统 Widget（MVP） |
| 游戏检测 | `PackageManager` + 云端游戏包名白名单库 |
| 前台监测 | `UsageStatsManager`（需 `PACKAGE_USAGE_STATS` 特殊权限）驱动计时和 Agent 免打扰 |
| 性能采集 | 前台 `Service` + `CoroutineScope`（5秒间隔协程轮询），读取 `/sys/class/thermal/`、`HardwarePropertiesManager`、`ActivityManager` 等系统 API；不可用指标优雅降级 |
| 心电图渲染 | 自定义 `View` + `Canvas`，环形缓冲区，60fps |
| Agent 规则 | 本地规则系统（条件→动作），JSON 配置可云端更新（见 7.1 规则示例） |
| 云端通信 | Retrofit + OkHttp，RESTful API，API Key 认证，接口版本前缀 `/v1/` |
| 精灵渲染 | Lottie 动画 + `WindowManager` 悬浮层（需 `SYSTEM_ALERT_WINDOW` 权限），形象与动效分层 |
| 画中画 | Android PiP API（API 26+） |
| 主题系统 | `ThemeConfig` 数据类，DataStore 持久化 |
| DI 框架 | Hilt 依赖注入，多模块间解耦 |
| 状态管理 | ViewModel + StateFlow / Kotlin Coroutines |

### 7.2 "猜你想玩"排序算法（MVP）

基于本地数据的加权评分：

```
score = 0.4 × 时段偏好分 + 0.3 × 近期频率分 + 0.2 × 最近启动新鲜度 + 0.1 × 总游戏时长分
```

- **时段偏好分**：统计该游戏在当前时段（如 18:00-21:00）的历史启动占比
- **近期频率分**：最近 7 天启动次数归一化
- **最近启动新鲜度**：距上次启动时间越短分越高（衰减函数）
- **总游戏时长分**：总时长归一化

取 top 2-3 作为"猜你想玩"展示。每次 Launcher 获得焦点时重新计算评分并更新 `GameRecord.category`。

### 7.3 权限请求流程

应用需要以下特殊权限，采用渐进式授权策略（用到时才请求，不在首次启动一次性弹出）：

| 权限 | 时机 | 拒绝后降级 |
|------|------|-----------|
| `QUERY_ALL_PACKAGES` | 首次启动（扫描游戏必需） | 无法自动扫描，仅支持手动添加游戏 |
| `PACKAGE_USAGE_STATS` | 首次启动（游戏计时必需），跳转系统设置页 | 无法统计游戏时长，数据中心功能受限 |
| `SYSTEM_ALERT_WINDOW` | 首次开启 Agent 精灵时 | Agent 以通知形式推荐，无桌面精灵 |
| `READ_CALENDAR` | 用户在 Agent 设置中开启"日历感知"时 | 日历维度不可用，不影响其他感知 |
| Health Connect | 用户在 Agent 设置中开启"健康感知"时 | 健康维度不可用，不影响其他感知 |
| `POST_NOTIFICATIONS` (API 33+) | Agent 首次主动推荐时 | Agent 仅在 Launcher 界面内推荐，无系统通知 |

每项权限请求前展示简要说明页，解释为什么需要及带来的好处。

### 7.4 直播/视频技术路径

| 方案 | 说明 | MVP 采用 |
|------|------|---------|
| 跳转原生 App | 检测已安装的直播 App（斗鱼/虎牙/B站），通过 Deep Link 跳转到对应直播间 | **是（主方案）** |
| WebView 内嵌 | 加载直播平台移动端网页版，在应用内观看 | 是（备用方案，未安装 App 时） |
| 自建播放器 | 对接平台开放 API 获取流地址，自行播放 | 否（需商务合作，二期评估） |

MVP 阶段以跳转 + WebView 备用为主，避免版权和技术风险。

### 7.5 数据清理策略

| 数据表 | 保留策略 | 清理时机 |
|--------|---------|---------|
| DeviceSnapshot | 保留最近 7 天，超过自动删除 | 每日凌晨 3:00 `WorkManager` 定时任务 |
| PlaySession | 保留最近 90 天 | 同上 |
| AgentEvent | 保留最近 30 天 | 同上 |
| GameRecord | 长期保留 | 用户手动删除 |
| 资讯缓存 | 最多 20 条，FIFO 替换 | 新数据到达时自动替换 |

### 7.6 离线与同步策略

- **离线期间**：所有行为数据（PlaySession、AgentEvent 等）正常写入本地 DB，Agent 本地规则引擎正常运行
- **联网恢复**：自动拉取最新资讯/直播/新游数据，刷新缓存
- **云端上传（可选）**：用户明确开启"数据同步"后，才上传脱敏行为摘要到云端推荐增强接口
- **缓存过期**：资讯缓存超过 24 小时标记为"可能过时"，直播数据不缓存

## 8. 云端 API

所有接口前缀 `/v1/`，认证方式为请求头 `X-API-Key`。

### 8.1 接口概览

| 接口 | 说明 | 频率 |
|------|------|------|
| `GET /v1/news` | 电竞资讯列表 | 用户刷新 / 30分钟轮询 |
| `GET /v1/live` | 赛事直播列表 | 5分钟轮询 |
| `GET /v1/videos` | 精彩集锦视频 | 用户进入时拉取 |
| `GET /v1/games/new` | 新游推荐列表 | 每半天一次（12小时间隔） |
| `GET /v1/games/whitelist` | 游戏包名白名单 | 每日一次 |
| `GET /v1/agent/rules` | Agent 规则更新 | 每日一次 |
| `POST /v1/agent/enhance` | 推荐增强（脱敏摘要） | 按需 |

### 8.2 核心接口 Schema

**GET /v1/news**

请求参数：

```json
        "is_live": true,
        "live_url": "https://..."
      }
    ]
  }

```

**GET /v1/games/new**

响应：
```json
{
  "code": 0,
  "data": [
    {
      "package_name": "com.mihoyo.zzz",
      "display_name": "绝区零",
      "icon_url": "https://...",
      "poster_url": "https://...",
      "description": "米哈游全新动作游戏",
      "store_url": "https://play.google.com/store/apps/details?id=com.mihoyo.zzz",
      "tags": ["动作", "RPG"]
    }
  ]
}
```

**错误响应统一格式**：
```json
{
  "code": 1001,
  "message": "Invalid API key",
  "data": null
}
```

错误码：`1001` 认证失败，`1002` 参数错误，`2001` 服务端异常，`3001` 限流

**客户端重试策略**：`2001` 服务端异常采用指数退避重试（最多 3 次，间隔 2s/4s/8s）；`3001` 限流遵循响应头 `Retry-After` 指定的等待时间。
